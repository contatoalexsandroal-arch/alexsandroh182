# The West Scripts

Scripts de automação para o jogo The West

## Scripts Disponíveis

- **ChurchBot v2** - Bot automático para construir igrejas com gerenciamento de buffs

## Como Usar

1. Instale o Tampermonkey ou ViolentMonkey no seu navegador
2. Abra o arquivo `.js` do script desejado
3. Copie todo o conteúdo
4. Crie um novo script no Tampermonkey/ViolentMonkey
5. Cole o conteúdo
6. Salve

## Buffs Suportados

- Decoração de bolo (Motivação +25%)
- Cigarro com filtro (Motivação +7%)
- Tampa de metal para garrafa (Energia +30%)
